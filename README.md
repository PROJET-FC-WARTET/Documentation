# Documentation — Projet Wartet FC

Ce dépôt centralise toute la documentation du projet : cahier des charges, Use Cases, spécifications et annexes.

## 📂 Organisation

| Dossier | Contenu |
| :--- | :--- |
| **`CAHIER-DES-CHARGES/`** | Cahier des charges officiel du projet |
| **`USE-CASES/`** | Spécifications fonctionnelles (Use Cases) |
| **`.github/`** | CODEOWNERS et templates de Pull Request |

## 🎯 Objectif

Ce dépôt est la **référence unique** pour comprendre les besoins du club. Le code (Backend, Frontend, Scripts) doit s'y conformer.

## 📖 Comment utiliser ce dépôt ?

- **Pour comprendre le projet :** Lisez le cahier des charges en premier.
- **Pour rédiger un Use Case :** Copiez le fichier `USE-CASES/_TEMPLATE_UC.md` et remplissez-le.
- **Pour proposer une modification :** Ouvrez une branche, faites vos changements et ouvrez une Pull Request.

## 🔒 Fichiers protégés

Certains fichiers nécessitent une validation du professeur avant fusion (voir `.github/CODEOWNERS`).
